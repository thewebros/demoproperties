# Asterra Estates — Real Photo Demo

This demo keeps the original dark editorial theme and uses real photography from Unsplash for presentation purposes. The property listings, prices, locations and descriptions are sample/demo content and must be replaced with verified client data before publication.

The photos are used as remote Unsplash image URLs, so the GitHub Pages site needs an internet connection to display them.

## Pages
- `index.html` — homepage
- `areas.html` — area selection
- `hisar.html`, `hansi.html`, `bhiwani.html`, `fatehabad.html` — location property grids
- Individual `*-1.html` to `*-4.html` files — property detail pages
